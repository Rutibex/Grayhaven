# Contributing

Thanks for your interest in Greyhaven. Please open an issue describing an intended change before a large implementation. Keep changes narrow and maintain the distinction between **original MIT code**, **GPL-covered server work**, and **third-party source**. Do not import proprietary game data or copyrighted game art. Test content, combat and editor changes with the project's documented scripts, and include reproducible steps for any reported bug.

Contributions of media must include origin/provenance and an explicit written license acceptable to the project. This repository has intentionally not declared a blanket license for the original game content.
