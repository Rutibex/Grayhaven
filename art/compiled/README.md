# Compiled proof assets

Generated by `tools/art/build_art.py`. Open `preview.html` offline, `contact-sheet.png` for facing/clip review, or `walk-proof.gif` for the walking loop. `manifest.json` is the runtime visual contract; `checksums.json` covers every PNG. Source cutouts and extraction rectangles are preserved alongside the atlases for review.

Do not edit atlas frames individually. Rebuild from original sheets and the shared rig, then validate the resulting images. Native and browser previews consume the same output.
