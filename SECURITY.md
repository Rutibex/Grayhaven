# Security policy

Greyhaven is currently an experimental, locally hosted, **single-player** game. It is not presented as a hardened public server or supported online multiplayer product. Do not expose its local services to untrusted networks or port-forward them. Avoid attaching private save files, credentials, or personal logs to public GitHub issues. For security-sensitive reports, contact the repository maintainer privately through the GitHub account that publishes this repository rather than posting exploit details publicly.
