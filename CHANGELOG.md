# Changelog

## v0.8.0-preview — Original art and audio milestone

- Added directional enemy presentation for Shore Raider, Reef Slinger, Salt Hexer and Brineguard, plus expanded resident, equipment, building, icon and UI art.
- Added polished quest, skills, journal, and trading panels and new effects.
- Included 39 original PCM sound cues (effects, ambient sound and regional musical pieces).
- Added F8 audio settings for Master, Effects, Music, and Ambience, with mute/preview controls.
- Preserved Phase 7 campaign compatibility and the existing island, quest and inventory object identities.
- Packaged a cleaner **player Windows ZIP** separate from the developer/source repository for GitHub distribution.

**Important:** this is an early single-player prototype. Co-op and final clean-machine Windows certification have not been completed.

Earlier internal milestones (foundations, art rig proof, game/server boot, save slots, inventory, combat and magic, island/editor, and quests) are recorded in `docs/PHASES.md`.
